# Polymarket BTC 15-Minute Binary Option Pricer

A small educational project to understand the pricing and risk of binary
options using Polymarket's BTC Up/Down 15-minute markets.

## Goals

- Understand cash-or-nothing binary option pricing
- Implement a Black-Scholes digital option pricer
- Estimate short-term BTC volatility
- Explore delta and time-to-expiry effects
- Extend the model to Polymarket's TWAP-based settlement
- Compare model fair values with Polymarket market prices

## Data

- BTC market data: Binance
- Prediction market prices: Polymarket CLOB API
